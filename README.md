# Квартира 14

Психологический хоррор от первого лица в браузере (Babylon.js). Советская квартира, метель за окном,
пропавшая 27 лет назад сестра и то, что жило в квартире всё это время.

Разработчик — [@w_dtc](https://t.me/w_dtc)

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173. С телефона в той же Wi-Fi сети — `http://<IP компьютера>:5173`.

## Управление

- ПК: WASD — идти, Shift — бежать, E / клик — взаимодействовать, F — фонарик, Esc — меню и настройки.
- Телефон: левая половина экрана — идти, правая — смотреть; кнопки «Рука», «Свет», «Бег».

## Как устроено

- `src/` — игра: мир, игрок, сущность, процедурный звук (Web Audio), сюжет.
- `public/models/` — модели из Blender (`mobile/` — облегчённые, текстуры 512 px).
- `art/` — скрипты Blender, которыми построены квартира, двор, сущность и анимации, и текстуры.
  Фотосканы — [Poly Haven](https://polyhaven.com) (CC0).
